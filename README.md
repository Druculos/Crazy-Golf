# Bounce Game (Godot 4.7 golf prototype)

Hit the ball as far and as high as you can through six connected zones:
Meadow → Rocky Highlands → Ancient Ruins → Jungle Temple → Mountain Shrine → Mystic Stones →
Sunny Coast → Windmill Farm → Autumn Woods → Volcano Ridge → Sky Isles → Royal Castle →
Frozen Peaks → Desert Oasis → Mushroom Grove → Candy Land → Starlight Summit → Coral Lagoon → Bamboo Forest →
Golden Savanna → Lavender Fields → Neon City → Red Rock Canyon → Cloud Kingdom → Spooky Hollow → Crystal Caverns →
Golden Palace (2600 yd in all).
Each stage has its own colour theme that blends into the next (`art_source/tools/zone_palette.py`).

**Runs:** every run is 3 shots. After the first swing the ball keeps going from wherever it stops; the run total
is your score, and your best run is shown at the top with the trophy.

## Open it
Godot → **Import** → pick `project.godot` in this folder → **Run** (F5).

## Controls
| Key | Action |
|---|---|
| Mouse (point) or Up / Down | Aim (10°–80°): the arrow points toward the mouse cursor |
| Hold Space or left mouse | Charge power (the meter swings up and down) |
| Release | Swing |
| 1–5 or Q / E | Switch between clubs you own |
| U | Open / close the upgrades shop |
| R | Start a new run from the tee |
| Mid-air: SPACE / click | Air Jump (if bought) |
| Mid-air: hold SPACE / click | Glider (when no jumps are left) |
| Mid-air: F / right-click | Rocket (if bought) |
| 1 / 2 / 3 / 4 in the shop | Switch between the Upgrades, Power-ups, Rebirth and Future Clubs pages |

## Coins, upgrades and clubs
Every shot pays 1 coin per yard, times a **stage bonus** for where the ball lands: x1 in zones 1-2, x1.5 in 3-4, x2 in 5-6,
x2.5 in 7-8, x3 in 9-10, x3.5 in 11-12 (`stage_mult()` in `scripts/main.gd`). Coin Bonus adds +20% per level on top.
Spend coins in the shop (U):

| Upgrade | Effect | Levels |
|---|---|---|
| Power | +8% launch speed per level | 10 |
| Bounce | keeps a bit more speed per bounce | 8 |
| Roll | less grass drag and friction, so the ball rolls further | 8 |
| Ring Boost | +4% extra speed from boost rings | 8 |
| Coin Bonus | +20% coins per shot | 10 |

## Rebirth and the Future World
Shop page 3. Rebirth costs 300,000 coins (`REBIRTH_COST`). It resets all upgrades and power-ups to level 0 (clubs are
kept) and in return:
- **Future World:** the course becomes a brand-new world of 20 connected futuristic stages — Neon Launchpad, Hover
  Highway, Robot Factory, Solar Fields, Cyber Garden, Hologram Plaza, Maglev Station, Bio-Dome, Data Valley, Quantum Lab,
  Mech Yard, Sky Arcology, Satellite Array, Space Port, Moon Base, Asteroid Field, Orbital Ring, Nebula Gardens,
  Time Rift and Star Gate (art in `assets/zones_future/`, generated by `art_source/tools/make_future_zones.py`).
- **Coin multiplier:** coins x2 after the first rebirth, +1 for every rebirth after that (`rebirth_mult()`).
- **Future Clubs** (shop page 4): Neon, Plasma, Quantum, Nova and Singularity — futuristic versions of the five clubs with
  exactly the same power and price (`FUTURE_CLUB_LOOKS`, art from `make_future_clubs.py`).

Further rebirths keep you in the Future World and raise the coin multiplier. Click the button twice to confirm; the
game reloads straight into the new world.

## Boost rings
About 90 golden hoops are spread along the whole course (`_ring_layout()`): mostly low/mid, some high, and some chains of three.
The layout is random and **moves to new spots after every 3 runs** (`RUNS_PER_SHUFFLE`; the HUD shows how many runs are left).
Each hoop in a run gives 70% of the previous one's boost (`BOOST_DECAY`): +12%, +8%, +6%, +4% ..., higher the further out they are (`RINGS` in `scripts/main.gd`:
world x, height above ground). The first hoop in a run adds +12% speed (+4% per Ring Boost level) plus a small lift, with a fire trail for 1.2 s.
Each hoop works once per run.

Clubs: Wooden ×0.5 (free), Silver ×0.575 (1,500), Gold ×0.65 (5,000), Diamond ×0.75 (15,000), Obsidian ×0.875 (40,000).

**Power-ups** (shop page 2, recharge every shot): Air Jump (1,200), Glider (1,800), Rocket (2,500), Super Bounce (1,500);
each has 6 levels (price doubles per level). Air Jump: 1 hop per level, each hop a bit lower. Glider: 1.2 s per level and
slower falling. Rocket: 1/2/3 blasts at Lv1-2/3-4/5-6; each blast is a short speed burst that fades back out after 0.7 s (no lasting momentum), slightly stronger per level. Super Bounce: 1 full-speed bounce per level.
Upgrade prices grow each level (`UPGRADES` in `scripts/main.gd`). Progress saves automatically to `user://save.cfg`;
delete that file to start over.

## How it's built
Everything is set up in code in `scripts/main.gd` (the scene `main.tscn` is just the root node):

- **Golfer:** drawn in code (`Golfer` + `Arms` classes). The arms pivot at the shoulder and hold the current club's icon;
  the backswing follows the power meter, and the ball launches at the moment the downswing reaches it.

- **Parallax:** one `Parallax2D` per layer, holding twenty-seven zone images side by side (each 1920×1080).
  Horizontal scroll speeds are sky 0.3, mountains 0.5, hills 0.7, trees 0.85, ground 1.0. Vertical speed is 1.0 for all,
  so the sky extensions (stacked 1080 px above each sky image) come into view when the ball flies high.
  Above them is a solid `#3b9fe8` fill, so the sky never runs out.
- **Ground and bounces:** solid ground that follows the exact curve of the ground art (`ground_y()`). The physics engine's own
  bounce is off; `_on_ball_contact()` reflects the ball off the ground at half speed (`BOUNCE_KEEP`), and grass drag stops
  the roll, so a shot settles about a second after it lands.
- **Distance:** 19.2 px = 1 yard, which matches the zone signs (100 yd per zone). The tee is at x = 960.
- **Tuning:** `BASE_SPEED`, the `CLUBS` power values, and the ball's `PhysicsMaterial` (bounce/friction) control how far shots go.

## Test mode
`Godot --path . -- --autoplay --shots=/some/folder` hits one Obsidian shot by itself and saves screenshots.

## Art and audio
- `assets/art/`: golfer rig (body, arms, celebrate pose), ball + trail sparkles/fire, tee + tee mat, hit spark,
  dust puff, grass bits, boost burst, coin, upgrade icons, UI kit (9-patch panel, buttons, power bar), distance
  flags (100-2600 yd), boost rings (back/front halves) and the logo. Most sprites are drawn at 2x and shown at 0.5 scale.
- `assets/audio/`: music (loops), ball hit, coin, grass bounce, level-up (also used, pitched up, for rings).
  See `assets/audio/CREDITS.md` and check each track's license before publishing.

## Art sources
`art_source/` holds everything used to make the art (Godot skips it thanks to `art_source/.gdignore`):
SVG/PNG versions of the zones, sky extensions, clubs and the original meadow background, the 3D 7-iron
(`golf_club.blend`), the game art SVGs (`art_source/game_art/`), and the generators in `art_source/tools/`
(`make_game_art.py` for sprites/UI, `render_logo.gd` for the logo, `render_thumbnail.gd` for the 16:9 thumbnail and
the itch.io cover in `art_source/thumbnail/`, `contact_sheet.gd` to preview a batch,
`make_golf_zones.py --no-signs` for the ground layers used in-game). After regenerating art, re-render the PNGs with
`Godot --headless --script art_source/tools/svg_to_png.gd -- <in.svg> <out.png> [crop_y crop_h]` and copy them into `assets/`.

## Web version
`web_export/` holds the browser build (`index.html` + engine and game data, ~49 MB). It isn't committed to git:
re-export after changes with Godot → Project → Export → **Web** → Export Project (or
`Godot --headless --path . --export-release "Web" web_export/index.html`).

- **Play it locally:** double-click `web_export/Play Bounce Game.command` (starts a local server and opens the browser).
  Opening `index.html` directly won't work — browsers block Godot games loaded from a file.
- **Put it online (itch.io):** zip the *contents* of `web_export` (not the folder itself, and you can leave out the
  `.command` file), create a new project on itch.io, set "Kind of project" to **HTML**, upload the zip, tick
  **"This file will be played in the browser"**, and set the viewport to 1280 × 720. The export is single-threaded,
  so no special server headers are needed.
